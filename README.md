# موقع فزعه FAZAA

## الصفحات
| الصفحة | عربي | إنجليزي |
|---|---|---|
| البطاقات (الرئيسية) | index.html | index-en.html |
| طلب البطاقة | order.html | order-en.html |
| ملخص الطلب | summary.html | summary-en.html |
| لوحة التحكم | admin.html | (نفس الصفحة) |

## التشغيل على جهازك
```
npm start
```
ثم افتح http://localhost:3000

## النشر على Railway
1. ارفع كل الملفات دي على مستودع GitHub.
2. من Railway اختر **New Project ← Deploy from GitHub repo** واختر المستودع.
3. Railway هيتعرف على المشروع لوحده من `package.json` ويشغّل `npm start`.
4. من **Settings ← Networking** اضغط **Generate Domain** عشان تاخد رابط للموقع.

## لوحة التحكم
افتح `/admin.html`.

- الطلب يوصل للوحة **مباشرة** أول ما العميل يضغط "تأكيد ومتابعة" في صفحة الطلب (حالته: لم يكتمل)، ويتحول إلى "مؤكد" لما يضغط "تأكيد الطلب" في صفحة الملخص.
- اللوحة تتحدث تلقائياً كل 4 ثواني، وتظهر رسالة عند وصول طلب جديد.
- عدّاد "الزيارات النشطة" يحسب الزوار الفاتحين الموقع حالياً من أي جهاز.

## إعدادات Railway (مهمة)
1. **كلمة المرور:** من Variables أضف `ADMIN_PASSWORD` بكلمة مرور قوية (الافتراضية `fazaa2026`).
2. **حفظ الطلبات بشكل دائم:** Railway بيمسح الملفات مع كل نشر جديد. من Settings أضف **Volume** واربطه بمسار مثل `/data`، ثم أضف متغير `DATA_DIR=/data`. بدون الخطوة دي الطلبات هتضيع مع كل تحديث للموقع.
